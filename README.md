# 🏠 US House Price Analysis

## 📌 Project Overview

US House Price Analysis is a collaborative data analysis project developed by a team of five members. The project focuses on analyzing housing data and identifying factors associated with house prices using statistical analysis and Multiple Linear Regression.

The project covers data cleaning, exploratory data analysis (EDA), regression modeling, model diagnostics, and data visualization.

## 🎯 Project Objectives

- Clean and prepare housing data for analysis.
- Explore data distributions and relationships between variables.
- Identify factors associated with housing prices.
- Apply Multiple Linear Regression to examine relationships between housing features and prices.
- Evaluate regression assumptions and interpret analytical findings.

## 👤 My Contributions

As one of the five team members, I was primarily responsible for the following tasks:

### 1. Data Cleaning & Preprocessing
- Inspected the raw dataset and examined data quality.
- Checked missing values and data consistency.
- Prepared variables for statistical analysis.
- Converted categorical variables into numerical representations.
- Applied One-Hot Encoding where appropriate.
- Prepared the cleaned dataset for regression analysis.

### 2. Multiple Linear Regression
- Developed a Multiple Linear Regression model using Ordinary Least Squares (OLS).
- Applied log transformation to the target variable.
- Examined relationships between explanatory variables and housing prices.
- Conducted regression diagnostics and evaluated model assumptions.
- Assessed multicollinearity and residual characteristics.

## ⚙️ Project Methodology

### 1. Data Cleaning & Preprocessing
- Data inspection and quality checking.
- Categorical variable encoding.
- Data transformation and preparation.

### 2. Exploratory Data Analysis (EDA)
- Descriptive statistics.
- Distribution analysis.
- Relationship analysis between housing features and prices.

### 3. Multiple Linear Regression
- Ordinary Least Squares (OLS).
- Log transformation of the target variable.
- Regression coefficient analysis.

### 4. Model Diagnostics & Evaluation
- Variance Inflation Factor (VIF) for multicollinearity assessment.
- Shapiro-Wilk test for residual normality.
- Breusch-Pagan test for heteroscedasticity.
- Root Mean Squared Error (RMSE) for model evaluation.
